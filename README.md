# 投资决策水平测试

一个轻量的投资者自测小工具：10 道题，根据总分映射到 5 档可枚举的等级，并给出一段幽默偏毒舌的专属点评，不同等级配不同的主题色。

## 在线访问

开启 GitHub Pages 后访问：

```
https://<your-github-username>.github.io/<repo-name>/
```

## 等级（5 档，可枚举）

| 分数区间 | 等级标题     | 一句话点评                             |
| -------- | ------------ | -------------------------------------- |
| 0 – 20   | 投机赌徒     | 你不是在投资，你是在给券商和对手盘众筹 |
| 21 – 40  | 韭菜学徒     | 学费交得很努力，但交的姿势还不太对     |
| 41 – 60  | 清醒的韭菜   | 已经知道自己是韭菜了，这本身就是进步   |
| 61 – 80  | 老练玩家     | 市场不会特别温柔，但会给你应得的那份   |
| 81 – 100 | 冷血复利机器 | 聚会里最无聊，但账户最厚的那种人       |

## 功能特性

- 纯静态页面（HTML + CSS + JS），零构建，GitHub Pages 直接托管
- 答题流程是一个长列表，可来回滚动修改，全部答完后解锁"查看结果"
- 每个结果等级有独立主题色（赌场红 / 焦糖橙 / 冷静蓝 / 墨绿 / 金）
- 完整适配移动端（响应式布局、44px 触控区、iOS 安全区）
- 结果支持"复制结果"分享

## 本地运行

```bash
python3 -m http.server 8787
# 然后打开 http://localhost:8787
```

## 部署到 GitHub Pages

1. 创建一个公开仓库
2. 推送本地代码到 `main`
3. `Settings → Pages`，Source 选 `Deploy from a branch`，Branch 选 `main` / `/ (root)`，保存
4. 等 1-2 分钟访问上面的 URL
